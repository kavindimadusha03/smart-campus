# Project Overview

The Smart Campus platform is designed to streamline campus resource management and facility booking. It provides a comprehensive solution for students, lecturers, and administrators to:

•	Book campus facilities such as lecture halls, labs, and meeting rooms
•	Manage resources with availability windows and ratings
•	Track and report incidents through a ticketing system
•	Handle user authentication via Google OAuth with JWT-based security
•	Receive real-time notifications for booking updates and alerts
•	View dashboards with analytics and statistics for admin oversight

## Tech Stack

•	Backend: Spring Boot (Java 17) with PostgreSQL database
•	Frontend: Next.js (React 19) with TypeScript and Tailwind CSS
•	Authentication: Google OAuth + JWT tokens
•	Storage: Supabase for file/attachment storage
•	Deployment: Configured for Railway (backend) and GitHub Pages (frontend)

## Key Features

•	Role-based access control (Admin / Student / Lecturer)
•	Resource availability tracking and booking suggestions
•	Admin dashboard with statistics and trend analysis
•	Notification system for booking approvals/rejections
•	Incident/complaint management with comments and attachments
•	Responsive UI with calendar views and data visualization
